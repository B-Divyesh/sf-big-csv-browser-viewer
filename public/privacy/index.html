Your file stays in this tab

Glassline reads your file in browser memory. It does not send file contents, filters, queries, or exports to a server.

What this site stores

The offline cache stores application files, artwork, and the public sample file. It never stores a file you choose or its results.

Demo work also stays in memory. Resetting or leaving the demo discards it.

Requests and logs

The app loads runtime files from this site only. It has no analytics, advertising, trackers, remote fonts, or third-party scripts.

Hosting logs may contain the request time, path, IP address, and browser details. Operators use them for reliability and abuse prevention.

Your control

Close or refresh the tab to clear the active workspace. Clear this site’s browser data to remove the offline cache.
